# Francesca Ferlauto — Wedding Planner Sicilia
## Portfolio Demo Project by Luca Cantale

### Setup
1. Scarica tutte le immagini elencate sotto
2. Mettile nella cartella `img/` con i nomi indicati
3. Apri `index.html` nel browser

### Suggerimento
Per un look coerente, cerca immagini con:
- Toni caldi (terracotta, sabbia, dorato)
- Luce naturale mediterranea
- Ambientazioni outdoor / costiere
- Stile elegante ma non freddo
